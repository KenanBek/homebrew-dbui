# homebrew-dbui

Homebrew tap for [dbui](https://github.com/KenanBek/dbui).

```sh
brew tap kenanbek/dbui
brew install dbui
```

The formula is published here automatically by each dbui release.

> Previously the tap lived inside the main repo (`brew tap kenanbek/dbui https://github.com/kenanbek/dbui`).
> If you have that old tap: `brew untap kenanbek/dbui` first, then tap as above.
